## 1. 何を伝える映像か — 確定した目的

「Restro」（Restore Stroke）は、重なって一体に見えるベクター輪郭から筆画ごとの形状を**推定して再構成**し、After Effectsで独立したシェイプとして編集できる製品。「文字を切る」「輪郭を裁断する」「一文字ずつ分ける」のではない。交差で隠れていた形まで推定されるため、元の輪郭を見ているだけでは分からない独立形状が得られることを**実際のRestro出力**で見せる。

情報の流れ：**導入 → 普通の分解との違和感 → 同一文字上で処理原理 → 復元筆画による作品例 → 実際のAE操作 → 締め・販売情報**。主目的は関心・理解・購買。機能一覧、Web UI風カードの羅列、抽象図形だけの映像にしない。処理は推定であり、元の筆順・意図・形状の完全復元を断言しない。

## 2. 保護する演出と再設計する部分

### 変更禁止の本質

- **B（beat 10〜17）**：**大きな同一の「筆」一文字**を固定し、その輪郭上に解析→延長→隠れた部分の推定→筆画への再構成という処理結果を、フィルターのように**時間とともに重ねる**。既存のSTEP・帯状タブ・拡大レンズの発想を継承する。2×2の工程カード／4文字の比較図に変更しない。
- **A2（beat 5〜8）**：Restro出力の独立筆画を大きく見せ、通常の裁断では得られない交差の奥の連続形状を見せる。単なるパーツ飛散では不可。
- **C**：複数の**完成した作品**を、右側の**縦方向にスクロールする映像ストリップ**で見せる。
- **D**：**複数の実AE操作録画**を、それぞれ独立したウィンドウで**非同期に登場・再生**。Cの縦スクロールを使い回さない。
- 背景のグリッド、左のブランド／説明、右の映像主役という構成、白黒を主とするトーン、Restroの赤は継承する。意図的な大きなはみ出しと、意図しない文字・映像の衝突は区別する。

### 固定しないもの

細かな座標、表示倍率、ラベルサイズ、各作例の色、操作窓の数とサイズ、演出のイージング、左右ゾーンの厳密な境界は**初期案**。既存AEPを読み、視認性・意味・時間的連続性を満たすよう調整できる。シーンの役割を変える場合のみ新たな設計判断として記録する。

## 4. 画面・文字のデザイン

> 共通のタイポ・配色・余白・ブランド・コピー・モーションの確定基準は
> `docs/design-baseline.md`（WU-0）を正本とする。本節の数値は候補値であり、
> 確定値は design-baseline 側を参照する。

### ゾーン設計（実測ベース）

- 左：ブランド表示とシーンの説明。実測は `description` が master 上 pos(32,585)・416×298、`Heading`(0,0)、`Ae.png`(0,100)、`Logo`(100,100)、`AFTER EFFECTS PLUGIN`(100,0)。実効的な左カラムは **x≈0〜460**。
- 右：主役となる文字／工程／作品／録画。**x≈480〜1080**。`x=460〜480` は安全距離の目安。
- 意図的に画面外へはみ出す巨大文字は許容する。**意味のある文・工程ラベル・操作対象が隠れる重なりは不可**。安全距離は実画面で判断する。
- グリッドは表示面と位置決めの共通言語。装飾枠を増やすための道具ではない。
- 情報の優先順位：主役の映像／左の一文／補足。不要な英語注釈は削るが、ブランドの `AFTER EFFECTS PLUGIN` や実AE UI、正規のURLまで禁じない。
- 主コピー36px、補足24px、タブ22px等は**候補値**。実レンダーで可読性を確認する。下限値を機械適用してはみ出すなら文字量・表示方法・配置を優先して直す。
- コピー入れ替えはモーションを伴ってよいが、文字同士が同時に読めなくなる残像・衝突を起こさない。

### 左コピー（意味を保ち、全文確定は実画面で）

| 区間 | 主文 | 備考 |

## 5. シーン別の表現と受入条件

### A1 `[0,45)`：既存の導入を保護

- 現状の巨大な「解」と独立筆画のズレ・復帰、左ブランドを継承。最初の4拍は**既存PNGと一致することを原則**とする。
- 既存レイヤーのアウト点を延ばしてA2を作らない。A2には必要な範囲を複製して別プリコンポに隔離する（本仕様では `PV A2` を新設）。
- A1のコピーを差し替えない。

### A2 `[45,90)`：普通の裁断と違う「復元された一画」を見せる

- 主役は巨大な「解」の右部にある交差した縦画・横画。既存の実Restro出力 `bunkai` の `runs4` 群（`STROKE_016_runs4`＝縦、`STROKE_015_runs4`/`STROKE_017_runs4`＝横）を **`PV A2` に複製して隔離**する。元レイヤーは変更しない。
- 見せたいのは「交差で見えなかった部分まで連続した一本の縦画として成立している」こと。横画が途切れずに残るだけではRestro固有の証明にならない。元の文字輪郭／交差位置のゴーストと、引き離した縦画の隠れていた部分を対応付ける。
- 演出（候補、実レンダーで調整）：f45〜55で交差周辺を大きく見せる → f56〜66で縦画を分離 → f67〜78で横画を離し、復元された縦画の全体をアクセント色で強調 → f79〜89で比較状態を保持しBへ接続。
- パスを任意に裁断して作り直さない。色マット・ハイライトは復元された形のどの部分を示すかを検証する。**複製を別筆画の子にする手順を無検証で実行しない**。親子・座標・マットの追随を確認してから決める。
- **受入**：拡大された筆画が独立した一つの形として認識でき、どこが隠れていた部分か一目で追える。左の問いと映像が対応する。

### A3 `[90,101)`：原理説明への橋渡し

- 「解」から「筆」への視線の移行が主目的。上方向のスクロールは候補であり、次のBの大文字を予告する転換としてつなぐ。
- 個別レイヤーを飛散させず、全体・グループ移動を優先し、必要な差のみ時間差を付ける。
- CやDまで全て同じ上方向転換にすることは固定しない。

### B `[101,191)`：原理、同じ巨大な「筆」一文字

- 演出構造は**絶対保護**。現在のSTEP系コンポ、帯状の段階表示、ルーペを読み、別々の文字・独立した4カードに作り直さない。
- ひとつの文字を基準位置・輪郭で保ったまま、段階が進むと観測・強調される情報が積み上がる。「累積」は不透明な塗りを全て重ね続ける意味ではない。工程ラベルの履歴は保持し、幾何・補助線は必要に応じて色・透過・優先度を変え、説明対象が隠れないようにする。
- ステップ（現行コンポに対応）：01 輪郭を解析（`STEP1 outline`, f101〜123周辺）、02 輪郭線を延長（`STEP2 draft`）、03 隠れた頂点を推定（`STEP3 draft`, `Lens magnifier`）、04 筆画として再構成（`STEP4 draft`, `Baseline`）。タブ／帯は順に追加。赤・緑・青・黄は役割に応じて使い、文字は読める濃淡・幅を確保する。
- 文字を収めるためだけに小さくしない。ルーペがタブ・本文・焦点を覆わない。
- **技術的注意**：マットの端から「内部延長線・推定頂点」を自動生成できるという主張は、実際の推定処理の証明ではない。実出力形状と処理契約を照合し、観察可能な幾何だけを可視化する。内部アルゴリズムにない処理を実動作として断言しない。
- ステップ04では同一文字上で各筆画が独立していることを少しの変位・配色・選択状態で伝える。「元の文字からバラバラの小文字に切替」では不可。
- **受入**：全時間を通して対象は同一の「筆」。各段階で何が増えたか分かり、ルーペは意味のある箇所を示す。工程ラベルと説明文が読める。Bの発想が破壊されていない。

### C `[191,281)`：作品例の**縦スクロール**

- 右側の**ひとつの縦長の窓**の内側に複数の「作品」を縦に並べ、上下に送る。各作品内にも筆画アニメーションがある。**主役はスクロール自体ではなく、認識できる完成作品。**
- 作品は3つ。どれも**実Restro出力**（`Baseline` の FUDE S01〜S13）で作り、色・運動・完成像の差が分かるようにする：
  - **A**「筆画が集まって文字になる」：散った筆画が本来の位置へ集まり「筆」が完成する。
  - **B**「完成した文字に筆画ごとの時間差の波」：完成状態から筆画ごとに時間差で押し出し／戻し、波が見える。
  - **C**「文字の筆画を使って別の構図を作る」：筆画を回転・再配置して別の構図へ組み替える。
- 窓は右ゾーン（x≈480〜1080、y≈60〜1020）に置く。ストリップは縦長（例 1080×3240）で、各作品を600角程度で中央に合わせる。**最初の作品の上／最後の作品の下には隣接作品が無い**。空きを意図的な余白として設計するか、始点／終点演出を加える。
- **タイミング**：各作品が**実際に窓へ入った時刻**を基準に「完成像の認識→動き→収束」を割り付ける。完成形が中央で数フレームしか見えない状態にしない。尺が足りなければ密度か運動の種類を調整し、見えない時間へ演出を押し込まない。
- `startTime`/`inPoint`/`outPoint`/`stretch`/タイムリマップ/マット/合成順を実画面で検証する。
- **転換注意**：CはD開始（f281）で隠れるように終了させる。全幅の不透明レイヤーをDの上に残さない。
- **受入**：複数の作品で、移動中の断片ではなく全体の形・意図した動きが認識できる。スクロールとコンポ内動作が同期する。不要な空白・はみ出し・左本文の侵食がない。

### D `[281,371)`：実AE操作の**非同期マルチウィンドウ**

- Cとは異なり、独立した短い録画窓を複数配置し、それぞれが少しずつ違う時刻に始まって終わる。ランダムに見えるが配置はグリッド上で構成する。
- 配置（候補）：W1 主画面（分解前→分解後が同一録画内で分かる）を大きく、W2〜W4 補助を小さく。4等分はしない。
- 素材（既存、退避ブランチから採用）：
  - `ae-decompose-ops.mp4`：After Effects の画面で「解」に Restro の inferred anchor（緑の on-curve 点・青い tangent ハンドル・赤い推定頂点）が表示されている状態。**推定された交差内部の頂点が見える**ため、A2の「隠れた部分」の主張とDの操作証跡を同じ素材で担える。
  - `ae-stroke-animate.mp4`：生成された筆画（赤・緑の小さな矩形）が「Restro」の文字の上で移動している状態。
  - `ae-reprocess.mp4`：2回目の分解後の筆画の変形。
  - **収録素材が証明できる操作だけ**を扱う。架空のAE UI・偽の機能操作を作らない。
- 録画は1920×1080の**画面全体**のキャプチャである。右ゾーンの窓に置く時の切り出し位置は実測で決める（AE自身のレンダーで確認する。ffmpegの `-ss` とAEのデコードはこれらのファイルで一致しない）。
  - コンポのキャンバス: x 480〜1160, y 110〜580
  - Restroパネル（Decompose操作の層）: x 35〜235, y 120〜460
  - タイムライン（生成された筆画とキーフレーム）: 下部 y 700〜1080
- 配置したフレームで、押したボタン・結果・レイヤーなど必要部分が**判読できること**を合格条件とする。W2/W3/W4が常時動作することは要件ではない（操作結果の静止も意味がある）。
- **転換注意**：録画は1920×1080。右ゾーンの窓へ入れる際は無変形縮小で歪ませず、必要ならマスクでクロップし被写体が見えることを確認する。Eへの接続は候補。
- **受入**：窓はグリッドと情報優先度に沿い、左の文字を壊さない。実操作の前後と結果が追える。Cのスクロールとの演出差が明確。

### A-3. 実装中に確定した技術的事実（再発防止）

実機AE（26系）で作り直す際に判明した、繰り返し踏みやすい点。

- **`copyToComp` はダミーマスクを引き継ぐ**。FUDE筆画を複製すると `Q10` というマスクが付き、複製レイヤーが描画されない。複製直後に `ADBE Mask Parade` の全マスクを削除する（C/D/Eの共通手順。`scripts/pv/build-scene-*.jsx`）。
- **`copyToComp` は FUDE 筆画のパスそのものを壊す**。`Baseline` の `FUDE S*`（13枚）を `copyToComp` すると各グループの頂点が 20〜92 → 3 に潰れ、字形の一部しか描画されない（`verts=3`）。**文字はレイヤー単位では再利用できない**。正本は `Baseline` コンポの複製を使う（`scripts/pv/build-glyph.jsx`）。
- **`Baseline` の文字は 1080 フレームからはみ出す**。実測で文字の領域は x 602〜1290, y 296〜994（中心 946,645）。1080幅だと右側がフレームで切られる。**コンポを 1400px に広げた複製**なら文字全体が出る（切れていたのはフレームサイズだけだった）。
- **`FUDE outline base` / `FUDE outline inset`（マスク Q7/Q8/Q9 付き）だけでは文字が出ない**。文字を描くのは 13枚の `FUDE S*` で、これらが一つでも欠けると outline 側も描画しなくなる。`PV glyph` は**リグ全体を保持**して複製する（レイヤー削除は不可）。
- **複製した `Baseline` の文字の位置合わせ**。ネストしたコンポレイヤーのアンカーはコンポ中心（1400幅なら 700,540）なので、文字中心 (946,645) は `position + (246,105) × scale` に置く。Rotation Z をこのネストレイヤーに掛けると Anchor まわりに回らないため、回転は使わずフレーミング（全寸／切り取り／小寸）で差を出す形にした。
- **レイヤーを消しながら前方ループするとインデックスがずれて残骸が残る**。削除は後ろから（`for (i = numLayers; i >= 1; i--)`）行う。
- **`saveFrameToPng` はコンポの resolution factor に従う**。Full(1) で 1080px、Half(2) で 540px。`master` は factor 2（既定）で保存されているので、1080px のフレーム列を撮る時だけ一時的に 1 にして戻す。
- **既存コンポを再利用する時はサイズと尺を明示的に設定**する。`CompItem` は `width`/`height`/`duration` を後から変えられるが、設定を忘れると旧サイズ（例: 3240pxの scaffold ストリップ）のまま圧縮され、作品が窓で切れる。
- **マットは被写体レイヤーの直上に置く**。`trackMatteType = ALPHA` は「直上のレイヤー」を消費する。枠・マット・footageの順を `border / matte / footage` にし、マットは `moveBefore(footage)` で直上へ移す。
- **テキストの中央揃えは `set_text` ツール経由で行う**。`TextDocument.justification` を直接書くとこのホストではRIGHTになり、左揃え基準の座標で組むと文字が画面外へ流れる。
- **旧Eの筆画走査（`STROKE_*_runs5`/`runs6`）は15.17〜18.5秒に残っている**。新しい `PV end` と重なるため、`▾ (A) stroke runs5`/`runs6` を無効化する（削除せず無効）。無効化してもA1〜Bの拍1〜17は byte 一致のまま。
- **デコード経路で録画の内容が一致しないことがある**。ffmpeg の `-ss` とAEのデコードが同じファイルで異なるフレームを返す場合があったため、Dの窓の切り出しは**AE自身の `saveFrameToPng` で確認**した位置を基準にする。外部ツールのシークだけで構図を決めない。
- `saveFrameToPng` は変更を反映する（全レイヤー無効化で出力が変わることを確認）。ただし同一コンポを連続レンダーした直後に別状態を読むと古い結果が返ることがあるため、判定は最終レンダーの映像で行う。

### 10.3 再設計方針（§5の目的・受入条件は維持）

- **左カラム**: `description` 内の同時表示ブロックを各シーン1〜2に絞り、見出し（短文）+必要最小限の補足に再編集。`Heading` の20秒常時表示をやめ、シーンごとのコピーに切替えるか非表示化。日本語・英語の重複ペアは階層を分け、長文エッセイは削除または大幅短縮。各文の目的（何を伝えるか）から再構成し、配置の付け替えだけで済ませない。
- **視覚言語**: グリッド背景・巨大タイポ・Restroブランド・左右構成は維持。巨大文字の占有率を抑え、端でのクロップは「意図的なトリミング」として設計し直す。B/C/D/Eのモーション（出現・移動・切替）の速度曲線とイージングを統一し、カード枠・ラベル・matteの多用を減らす。
- **A2**: `PV glyph` 系の複製コンポ内で個別 `FUDE S*` レイヤーを直接アニメーション（表示切替・位置/回転・描画順）し、「交差でつながった輪郭の奥にある連続した一画」が分離・復元される様子を実形状で見せる。拡大のみの `kai-zoom` 継続では不可。
- **B**: 同一巨大「筆」への4工程累積を保持。タブ/カード/ラベルを工程進行に同期させて順次出現させ、ルーペの拡大内容と工程表示の色・位置を整理。master上の静的多重表示を解消する。
- **C**: 縦スクロール窓は維持。`PV work` を3つの**内容と動きが異なる**作品に作り替える。実Restro出力（`PV glyph`/`bunkai`/`BG decomposed strokes`等の個別筆画）を使い、書き順ドロー・筆画ごとの個別モーション・一筆画変形など、キャプションと一致する実作例にする。内部筆画アニメーションが `copyToComp` 以外の経路で可能かを先に検証する。
- **D**: 4窓構成は維持候補だが、各録画の内容を「操作→結果が読める」区間に再構成。不要UI・ダイアログ・判読不能な縮小を除き、必要ならAEで録り直す。窓の枠・matteは情報伝達に必要な最小限に。
- **E**: recapタイルと枠付き商品カードを廃し、直前シーンの筆画モーションから連続する構成へ。Restroの特徴（一画ずつ編集できる）と製品名・BOOTH導線が視覚的に記憶に残るエンディングに再設計。コピーは滞留時間を確保。
- **copyToComp問題**: comp複製で保持した内部 `FUDE S*` レイヤーに対し、レイヤーの `enabled`/`inPoint`/transformを直接キー化する方式を検証する。これが成立すれば個別筆画モーションの本来要件を満たせる。
