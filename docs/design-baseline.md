# Restro PV 共通デザイン基準（WU-0）

> 状態：**正本**。2026-11-25 制定。`docs/SPEC.md` §4 の候補値を実測・実レンダー
> 結果に基づいて確定したもの。シーン個別の演出仕様は SPEC §5 が優先し、
> 本書は全シーン共通のタイポ・配色・余白・ブランド・コピー・モーションの
> 確定基準を定める。変更する場合は SPEC と同じくレビューを経る。

## 1. キャンバスとゾーン

- 1080×1080、24fps、20秒（480フレーム）。
- 左カラム：ブランド表示とシーン説明。実効範囲 **x 0〜460**。
- 右ステージ：主役の映像。**x 480〜1080**。
- **x 460〜480 は安全距離**。意味のある文・図・操作対象をこの帯へ置かない。
- 背景は dumped のグリッド（`grid-solid` / `White Solid 1`、約 `#f7f7f7`）。
  シーン独自の背景色・写真背景・グラデーションは追加しない。

## 2. 配色

- 基調は**白黒**。文字・線画は `#111`（ dumped の実値は `[0,0,0]`〜`#111` 近傍）。
- アクセントは Restro の赤系のみ。工程フィルタ等の意味色は
  SceneB の確定値を使う：`#D64520`（解析・赤）`#2FA36B`（延長・緑）
  `#2F6FED`（頂点推定・青）`#E8A52F`（分割・黄）。
- 録画窓・カード等のUI要素は白地＋`#111` の細い枠を基本とし、
  影・角丸・グラデーションなどの「Web風装飾」は使わない
  （v10 不合格指摘「Webベースの稚拙なデザイン」への対応）。

## 3. タイポグラフィ

- フォントは **Noto Sans JP** 系（dumped の Kozuka Gothic Pr6N は
  text.tsx が同一系統へ置き換える）。字形の混在を避けるため、
  authored 層も同じスタックを使う：`'Noto Sans JP','Hiragino Sans',sans-serif`。
- サイズ階層（1080px 正方形基準）：
  | 用途 | サイズ | ウェイト |
  |---|---|---|
  | ヒーロー見出し（A1 等） | 74〜77 | 700〜800 |
  | シーン主コピー | 32〜40 | 700 |
  | 説明・補足文 | 24〜30 | 400〜500 |
  | 工程ラベル・小見出し | 22〜26 | 700 |
  | 録画窓内の補助表示 | 原則置かない | — |
- 最小可読サイズ：意味を持つ文は **22px 以上**。それ未満にするなら
  情報を削るか別の提示方法に変える。
- 日本語を主、英語は補助。機械的な日英対訳の併記はしない
  （ブランド表記 `AFTER EFFECTS PLUGIN`・製品機能名・URL は例外）。

## 4. ブランドとコピー

- 常設ブランドは dumped の `Logo` / `Ae.png` / `AFTER EFFECTS PLUGIN` を使う。
  **ロゴ・ワードマークを authored で描き直さない**（E の「ロゴ消失」指摘対応）。
- 確定コピー（変更には SPEC レベルの判断が必要）：
  - E 商品カード：`Restro` / `筆画復元` / `After Effects プラグイン` /
    `BOOTHで販売中` / `361do.booth.pm/items/9029239`
  - B 工程：`輪郭を解析` `輪郭線を延長` `隠れた頂点を推定` `一画ずつに分割`
  - 左コピーは SPEC §4 の表に従う。推敲は可、意味の無断変更は不可。
- コピーは「そのシーンで何を見せるか」に1〜2文で対応させる。
  長文エッセイ・重複する日英ペア・途中で切れた文は置かない。

## 5. モーション共通規約

- イージングは `easeOutCubic` 系を標準とし、出現・退場は 0.15〜0.5 秒。
  退場はハードカットより短いフェード（≈0.15 秒）を優先する。
- 画面に残る要素は「読ませる保持」を許容するが、3 秒以上まったく
  変化のない右ステージは避ける（情報優先度の問題として扱う）。
- カット・ワイプ等の場面転換は transition-design の判断に従い、
  意図しない要素の残留（全幅レイヤーの被り等）を残さない。

## 6. authored 層の作法

- 字形・筆画は `video/src/scenes/glyph.tsx` の StrokeField で
  **実筆画パスをそのまま**再描画する。似せた図形での代替は禁止（ADR-0005）。
- dumped が描画できる要素（グリッド・ロゴ・テキスト・枠・タブ）は
  dumped を保持し、authored 層は「描画不能」または「配置が要求を
  満たさない」部分に限定する（ADR-0005 第3項）。
- 各制作単位は局所レンダー＋独立レビューを反復し、全編レンダーは
  全単位が揃ってから行う（SPEC §11 実行条件）。
