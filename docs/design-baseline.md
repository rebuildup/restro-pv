# Restro PV 共通デザイン基準（WU-0）

> 状態：**正本**。2026-11-25 制定、同日改訂（枠組みの転換）。
> `docs/SPEC.md` §4 の候補値を実測・実レンダー結果に基づいて確認した
> 事実を収録するが、本書は**固定規則集ではない**。各要素がそのシーンの
> 目的に対して適切かを判断するための基準であり、値を機械的に当てはめて
> 映像表現を画一化してはならない。
> シーン個別の演出仕様は SPEC §5 が優先する。変更にはレビューを要する。

## 0. この基準の使い方

制作・レビューの双方が「この要素は目的に対して適切か」を判断するための
問いを提供する。以下の数値は dumped 実測値と検証済みの実用範囲であり、
**既定値**として使う。逸脱が演出意図を強める場合は逸脱してよいが、
逸脱の理由を SPEC またはレビュー記録に残す。

逆に、以下は「共通仕様として固定してはいけない」もの：

- ユーザーが v10 で否定した**囲み（カード枠・パネル）や Web 的構成**を
  全シーン共通の正解として固定しない。枠が必要なシーン（録画窓等）は
  SPEC §5 が個別に指定する。
- 余白・サイズ・モーション時間を全要素に一律適用しない。
  「読ませる要素」と「印象を作る要素」は基準が違う。

## 1. キャンバスとゾーン（実測・確定 — Issue #30）

> Issue #30 により本節のゾーン構成は**確定事項**へ昇格した。
> サムネイルと連続する旧制作レイアウト（背景・グリッド・ブランド・
> 左情報領域・右コンテンツ領域・配置・階層・スケール）は変更不可。
> 通常制作の編集範囲は右ステージのコンテンツのみ。実装上の権威は
> `video/src/layout/`（`docs/issue30-recovery.md` 参照）。

- 1080×1080、24fps、20秒（480フレーム）。
- 左カラム：ブランド表示とシーン説明。実効範囲 **x 0〜460**。
- 右ステージ：主役の映像。**x 480〜1080**。
- **x 460〜480 は安全距離**。意味のある文・図・操作対象をこの帯へ
  置かない。
- 背景は dumped のグリッド（`grid-solid` / `White Solid 1`、約 `#f7f7f7`）。
  シーン独自の背景色・写真背景・グラデーションを**安易に**追加しない。
  ただし背景自体が演出の主役になるシーンでは SPEC §5 の指定に従う。

判断の問い：左カラムの情報は右ステージの主役を食っていないか。
安全距離帯に意味が滲み出していないか。

## 2. 配色（実測・既定）

- 基調は**白黒**。文字・線画は `#111`（dumped 実値は `[0,0,0]`〜`#111`
  近傍）。
- アクセントは Restro の赤系と、SceneB 工程の意味色
  `#D64520`/`#2FA36B`/`#2F6FED`/`#E8A52F`。**色には意味を持たせる**
  （工程・強調・状態）。装飾目的だけの色追加はしない。
- UI要素は白地＋`#111` の細い枠を**基本**とする。影・角丸・
  グラデーション等の「Web風装飾」は v10 不合格指摘への対応として
  既定では使わないが、SPEC が要求する演出要素（ルーペ等）は
  そのシーンの仕様に従う。

判断の問い：この色・この装飾は何を意味するか。意味なく増えていないか。

## 3. タイポグラフィ（実測・既定）

- フォントは **Noto Sans JP** 系（dumped の Kozuka Gothic Pr6N は
  text.tsx が同一系統へ置き換える）。字形の混在を避ける。
- サイズの実用範囲（1080px 正方形基準）：

  | 用途 | 既定サイズ | 備考 |
  |---|---|---|
  | ヒーロー見出し（A1 等） | 74〜77 / 700〜800 | インパクト優先 |
  | シーン主コピー | 32〜40 / 700 | |
  | 説明・補足文 | 24〜30 / 400〜500 | |
  | 工程ラベル・小見出し | 22〜26 / 700 | |
  | 録画窓内の補助表示 | 原則置かない | |

- 意味を持つ文の**可読下限は 22px**。それ未満にするなら情報を削るか
  別の提示方法に変える。
- 日本語を主、英語は補助。機械的な日英対訳の併記はしない
  （ブランド表記 `AFTER EFFECTS PLUGIN`・製品機能名・URL は例外）。

判断の問い：この文字サイズは「読ませる」ためか「印象を作る」ためか。
その目的に対して適切か。ヒエラルキーがシーン内で成立しているか。

## 4. ブランドとコピー（確定・変更不可）

- 常設ブランドは dumped の `Logo` / `Ae.png` / `AFTER EFFECTS PLUGIN`
  を使う。**ロゴ・ワードマークを authored で描き直さない**。
- 確定コピー（変更には SPEC レベルの判断が必要）：
  - E 商品カード：`Restro` / `筆画復元` / `After Effects プラグイン` /
    `BOOTHで販売中` / `361do.booth.pm/items/9029239`
  - B 工程：`輪郭を解析` `輪郭線を延長` `隠れた頂点を推定` `一画ずつに分割`
  - 左コピーは SPEC §4 の表に従う。推敲は可、意味の無断変更は不可。
- コピーは「そのシーンで何を見せるか」に1〜2文で対応させる。
  長文エッセイ・重複する日英ペア・途中で切れた文は置かない。

## 5. モーション（判断基準・時間は既定）

- イージングは `easeOutCubic` 系を標準とし、出現・退場は 0.15〜0.5 秒。
  これは**既定**であり、効果音・カット・作品内のリズムに合わせた
  逸脱は許容する。機械的な統一が目的ではない。
- 退場はハードカットより短いフェード（≈0.15 秒）を**優先**するが、
  演出上ハードカットが正しい場合はそれを選ぶ。
- 画面に残る要素は「読ませる保持」を許容する。ただし**3 秒以上
  まったく変化のない右ステージ**は情報優先度の問題として扱い、
  変化・進行・カメラ的な動きのいずれかで生命を持たせるか、
  シーン自体を短くする。
- カット・ワイプ等の場面転換は transition-design の判断に従い、
  意図しない要素の残留（全幅レイヤーの被り・二重描画等）を
  残さない。**残留の検出はフレーム実見で行う**。

判断の問い：この動きは何を伝えるか。情報優先度に対して速度・
保持時間は適切か。シーン間のつながりは切れていないか。

## 6. authored 層の作法（変更不可の制約）

- 字形・筆画は `video/src/scenes/glyph.tsx` の StrokeField で
  **実筆画パスをそのまま**再描画する。似せた図形での代替は禁止
  （ADR-0005）。
- dumped が描画できる要素（グリッド・ロゴ・テキスト・枠・タブ）は
  dumped を保持し、authored 層は「描画不能」または「配置が要求を
  満たさない」部分に限定する（ADR-0005 第3項）。
- 共通の筆画素材契約は Issue #28 で管理する。シーン個別の
  sanitize/recolor の増殖を防ぐ。
- 各制作単位は局所レンダー＋**独立レビュー**（tools/wu-review.ts、
  verification/reviews/ の記録）を反復し、全編レンダーは全単位が
  揃ってから行う（SPEC §11 実行条件）。
