# wu-c-r4 — C->D boundary scene C exit and scene D entry boundary frames

## 総合判定
FAIL — C由来の「分解し／分角」の残留は解消されたが、f270〜f279のC区間からDの「AFTER EFFECTS PLUGIN／Restro／筆画復元」コピーが既に表示されており、C→Dのシーン切り替えが明確になっていない。

## 要件別
1. PASS — f270およびf276では右側の鏡像エンブレムが配色・形状ともに判別可能な完成状態として保持され、f279では減衰 Planificaciónだが全体形状はなお確認できる。
2. PASS — f281・f283では「分解し」「分角」およびそれに伴うC的作品説明・枠の残留は消えており、Dの左上コピーを覆うC由来テキストも確認されない。
3. FAIL — f270・f276・f279では、Dの「AFTER EFFECTS PLUGIN」「Restro」「筆画復元」コピーがC区間内に既に全面表示されている。一方、f281では右側の非同期録画窓がほぼ現れておらず、f283でも非常に薄い。このため境界で同一グリッド上にコピーだけ先行して残り、C→Dの明確な場面転換になっていない。
4. PASS — f270→f276→f279ではエンブレムが段階的に減衰し、f281で完全に消えている。f281・f283にも、輪郭の欠け、ゴミ状の描画、意図外の線分や面元素的破綻は確認されない。ただしf283の右側窓は極端に薄い。

## 具体的な問題点
- f270・f276・f279のC区間にDの主要コピーが先行表示され、シーン境界が曖昧。
- f281ではD側の四つの録画窓がほぼ確認できず、コピーのみ先行して見えるため、切り替えが単調な图层差し替えのように-ku cheap.
- f283の録画窓は表示が弱すぎ、D開始時の画面情報量と構成が急に不足して見える。
- 「分解し／分角」の残留自体は修正されており、今回の具体的な重なり問題はない。

## 修正提案
- Dの左上コピーおよび「Restro」「筆画復元」のグループを、完全に消去する прежはf281で開始するよう開始タイミングを再設定する。
- f279でCのエンブレムを減衰させつつ、D側の四つの録画窓をf281で十分な不透明度で開始させ、コピーと窓が同一のDエントリとしてまとめて見えるようにする。
- 必要ならgrid自体をD側へ切替・フェードし、「同一背景上でCの図形だけ消える」状態を避ける。
