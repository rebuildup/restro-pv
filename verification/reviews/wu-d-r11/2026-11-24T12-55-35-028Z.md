# wu-d-r11 — D entry scene D first frames after C->D cut

## 総合判定
FAIL — 窓の立ち上がりは判別可能になったものの、C→D の境界が左列で決定的でなく（Cのロゴ要素がそのまま残存）、Dの窓群は右端で切れたまま・f295のW2は白飛びでほぼ読めず、Dとして成立していない。

## 要件別
1. PASS — f281・f283 で右上の「録画窓」はチェッカー＋赤いアンカー点＋白い "Restro" マークとして輪郭が明確に判別でき、「ほぼ見えない／非常に薄い」状態ではない（f285 でさらに明瞭）。
2. FAIL — f279 と f281/f283/f285 の左列（青の Ae バッジ、"AFTER EFFECTS PLUGIN"、Restro ワードマーク、「筆画復元」大文字、隅の「文字の輪郭から、筆画ごとのシェイプへ。」）が完全に同一で、C の作品要素が D に残存している。変化したのは右側のパネルだけで、切り替えが部分的であり「唐突」ではなくとも、要素の入れ替わりが決定的でない。
3. PASS — f279〜f295 を目視した範囲、グリッド・文字の_ERR・座標点の実描画的な破綻（文字化け、線断裂、:type 崩れ）は無い。f295 でW2が白飛びするのはフェード内の状態であり、破綻ではない。
4. FAIL — D の窓群が成立していない。f281〜f295 で上パネルが画面右端（x=1080）で切れたまま、赤いアンカー点列の右側が見切れている。下側のW2（f295）は淡灰logeほぼ白に埋もれ、判読不能に近い。左コピーも C と同一のままで D の内容（アンカー追尾UI）と文面の対応が見えず、全体が AE の画面キャプチャ貼付けの「技術デモ」調で配置の 完成度が低い。

## 具体的な問題点
- f281/f283/f285: D の上パネルが画面右端でクリップされ、赤マーカー列が中途半端に切れている。
- f295: 下側窓（W2）が白/極淡で、白背景と同化し内容が見えない。
- f279 と f281 の左列が完全同一（ Ae ロゴ、"AFTER EFFECTS PLUGIN"、Restro 大文字、「筆画復元」大文字、隅のキャプション）— C の作品要素の残存。
- f285 の「頂点の推定」ラベルのように、説明ラベルが後から薄く上に載るだけのiblyで、主役にfinished なGUI 件名不见。
- 窓群が AE のスクリーンショット（チェッカー＋マーカー）の貼り付けで、PV として情報設計・余白・視覚 Hierarchy がなく、安価な技術デモ感。

## 修正提案
- D の窓群をUMB 1080 内に収める（例：パネル全体を 0.8 倍にスケールし、右余白 60px／上余白 60px で配置）.Red マーカー列の切れ端を見せない。
- W2 の不透明度・コントラストを上げ（背景を淡グレー〜薄い青に落とし、線と点を明确的色にする）、f295 時点で内容が読めるようにする。フェード時間を短縮して可視状態を早期に確保。
- C→D の境界を左列にも出す：左の大文字ロックアップとキャプションを D 用（例：「Control points／頂点から笔画を生成」等の D 固有コピー）へ差し替え、あるいは左列をクロスフェードで 1〜2 フレームで差し替えることで C の要素が残らないことを明示する。
- D の窓には「頂点の推定」以外の GUI 要素（タイトルバー、凡例、numeric 値など）を整え、スクリーンショット貼付けではなく意匠されたウィンドウとして hierarchy を作る。
