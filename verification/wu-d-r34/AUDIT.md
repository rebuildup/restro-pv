## 再録画の検討と結論

- AE 2026 はインストール済みだが**非起動**。`bun run generate` 経路は
  `AfterFX.exe -r` で JSX を実行できるが、必要な素材は **AE UI の
  画面キャプチャ**であり、JSX では UI 操作も画面収録もできない。
  Restro プラグインパネルのボタン操作は JSX 非対応（既存録画も手動
  キャプチャ + script 実行）。画面収録の自動化経路はリポジトリに存在しない。
- **結論: 再録画はこの環境では実行不能。**

## 欠けているもの（証跡として正確に記録）

既存3録画には「入力テキストが認識可能な分離筆画シェイプへ変換され、
完成形が保持される」一連の決定的区間が存在しない。必要な録画は:

1. クリーンな入力テキスト（単色・高コントラスト）。
2. 分解操作の実行（ボタン押下または script 実行が画面で追える）。
3. **認識可能な筆画シェイプへの分離** — コントロールポイントやハンドルの
   オーバーレイではなく、文字を構成する筆画そのものが分離・再配置された
   状態（例: 各筆画が離れて配置される、または色分けされた完成筆画群）。
4. 結果の静止保持（操作後の安定フレーム）。

これがあれば scene D の PROOF 要件を満たせる。現状の stroke-animate 版は
「筆画が実際に動く」editability の証拠としては最も誠実だが、M3 の
「分解→完成筆画」の基準には届かない。
