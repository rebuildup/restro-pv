付記
----
- 本テイクは AE の Mouse 実入力のみで成立させている。収録中に AE スクリプト
  （-r 委譲）を走らせないことが重要で、前回の失敗は「2 本目のスクリプトを
  起動した瞬間に AE が "Attempt was made to run a second script while another
  script was already running" を表示して操作が成立しなかったことによる。
- WGC は変化時のみフレームを出すため、静止区間は直前フレームを保持して
  24 fps 化している（可変 fps ではない）。
- 以前の試行テイク（take1 ほか）は D:\pv-tmp\rec-d\old-take* と
  stale-take2-partial に退避済みで、成果物には使っていない。
  verification/rec-d/take1 は指示どおり現物（左）を残置している（.gitignore 済み）。
